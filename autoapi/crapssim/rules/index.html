class crapssim.rules.CraplessRules

Bases: AbstractRules

Crapless craps rules.

In this variant, 2, 3, 11 and 12 are treated as points rather than immediate losses for the pass line and come family bets.

point_numbers() → list[int]

Return Crapless point numbers, including 2, 3, 11, and 12.

Returns:

Valid point numbers: 2, 3, 4, 5, 6, 8, 9, 10, 11, and 12.

Return type:

list[int]

come_out_winners() → list[int]

Return come-out winners for Crapless rules.

Returns:

7, the only come-out winner in Crapless craps.

Return type:

list[int]

come_out_losers() → list[int]

No come-out losers in Crapless craps.

list[int]
