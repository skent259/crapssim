# CrapsSim Engine API Roadmap

## Purpose

The Engine API exposes a lightweight HTTP/FastAPI wrapper over the CrapsSim engine so clients can start sessions, place bets, and retrieve table state without embedding the simulator directly.

## Phases

- **Phase 1 — Stabilization and Compatibility**
  - Phase 1-A — Compatibility Scan (Docs Only): completed. Captures engine/API drift and test baseline in `docs/dev/API_COMPAT_PHASE1.md`.
  - Phase 1-B — API surface alignment: planned.

- **Phase 3 — Performance and Load** (planned)
